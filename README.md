# Портфолио — Нестеренко Иван

Личный сайт: дизайн, вёрстка, разработка. Чистые HTML, CSS и JS без сборщика
и без зависимостей — открыл файл, поправил, обновил страницу.

**Живой сайт:** https://folvski.github.io
**Как публиковать:** [DEPLOY.md](DEPLOY.md)

Макет: `Mine portfolio WebSite` (Figma). Брейкпоинты `1920 · 1440 · 1024 · 768 · 390`.
Контейнер `1136px` на десктопе, `656px` на `≤1024`, на телефоне — вся ширина
минус поля. На `≤1024` меню сворачивается в бургер.

## Контроллеры

Каждый отвечает ровно за одно. Подключаются в `main.js`, **порядок важен**:
партиалы подставляются первыми, иначе контроллерам нечего искать в DOM.

| Файл | Что делает |
| --- | --- |
| `menu.js` | Бургер и подсветка текущей страницы |
| `reveal.js` | Появление блоков при прокрутке (`data-reveal`, `data-appear`) |
| `contacts.js` | Собирает карточки контактов из `data/site.js` |
| `pack.js` | Укладывает пилюли со стеком плотнее обычного переноса |
| `shine.js` | Блик, ползущий по обводке пилюль одна за другой |
| `works-nav.js` | Строка разделов на «Работах»: подсветка и сворачивание в стопку |
| `smooth-scroll.js` | Плавная прокрутка колесом |
| `anchors.js` | Переходы по якорям с учётом высоты шапки |
| `page-fade.js` | Переход между страницами через чёрный |
| `to-top.js` | Кнопка «наверх» |
| `cursor.js` | Свой курсор — стеклянный кружок вместо стрелки |
